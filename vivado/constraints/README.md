# Ràng buộc (XDC)

- `Zero7.xdc`: file ràng buộc mẫu đi kèm tài liệu hướng dẫn ZERO7 (lấy từ ban tổ chức / người cho mượn board).
- `top.xdc`: ràng buộc cho thiết kế chính (clock, chân GPIO nối Raspberry Pi). Script
  `../scripts/synth_xc7s25.tcl` đọc file này nếu có.

Gán chân theo bảng ZERO7 FPGA Connection Table (xem `docs/README.md`).
